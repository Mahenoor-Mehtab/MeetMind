# Changelog

All notable changes to **MeetMind** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-06-01

### 🎉 Initial Release

#### Added
- AI-powered real-time video calls via Stream Video SDK
- Custom AI agent support during live calls
- Stream Chat SDK integration for in-call messaging
- Post-call automatic summary generation using OpenAI
- Full meeting transcript generation via Inngest background jobs
- Meeting recordings with in-app video playback
- Full-text transcript search across all meetings
- AI meeting Q&A — chat with AI that understands your meeting context
- Meeting history page with statuses (upcoming, completed, missed)
- Better Auth — secure signup, login, and session management
- Polar subscription integration for plan management
- Mobile responsive UI across all pages
- CodeRabbit AI-assisted PR code reviews in Git workflow
- Next.js 15 App Router architecture
- React 19 support
- Tailwind CSS v4 + shadcn/ui component library
- Inngest background job pipeline for post-call processing
- OpenAI integration for agent intelligence and summaries
